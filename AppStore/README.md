# AppStore

## Description
An app store-like interface displaying a collection of applications with their details.

## Features
- Display list of apps with names, descriptions, and ratings
- Component-based architecture with reusable AppStore component
- Clean UI with card-based layout

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd AppStore
npm install
npm run dev
```
