# Banner

## Description
A promotional banner component displaying multiple marketing cards with headers, descriptions, and call-to-action buttons.

## Features
- Three distinct banner cards with different styling
- Card component reusability
- Data-driven rendering from array of objects
- Hover effects and visual hierarchy

## Tech Stack
- React (Vite)
- Functional Components
- CSS

## How to Run
```bash
cd Banner
npm install
npm run dev
```
