# DarkMode

## Description
A dark/light mode toggle component that switches the entire UI theme between dark and light modes with dynamic styling.

## Features
- Toggle between dark and light themes
- Dynamic background and text color changes
- Button text updates based on current mode
- Inline style manipulation based on state

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd DarkMode
npm install
npm run dev
```
