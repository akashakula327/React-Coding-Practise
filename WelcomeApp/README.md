# WelcomeApp

## Description
A welcome screen with a subscribe/unsubscribe toggle button that changes text based on subscription state.

## Features
- Welcome heading and thank you message
- Subscribe/Unsubscribe toggle button
- Dynamic button text based on state
- Boolean state management
- Clean centered layout

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd WelcomeApp
npm install
npm run dev
```
