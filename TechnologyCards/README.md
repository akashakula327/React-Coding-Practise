# TechnologyCards

## Description
A technology roles showcase displaying four career cards: Data Scientist, IoT Developer, VR Developer, and ML Engineer with descriptions and images.

## Features
- Four technology role cards
- Each card: title, description, image
- Unique styling per card (card-1 through card-4)
- Responsive grid layout
- Data-driven rendering from array

## Tech Stack
- React (Vite)
- Functional Components
- CSS

## How to Run
```bash
cd TechnologyCards
npm install
npm run dev
```
