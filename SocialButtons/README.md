# SocialButtons

## Description
A social media button component showcasing three button variants: Like (yellow), Comment (white), and Share (blue).

## Features
- Three distinct button styles
- Like button: Yellow background (#eab308)
- Comment button: White background (#ffffff)
- Share button: Blue background (#1d4ed8)
- Reusable Button component with props
- Flexbox row layout

## Tech Stack
- React (Vite)
- Functional Components
- CSS

## How to Run
```bash
cd SocialButtons
npm install
npm run dev
```
