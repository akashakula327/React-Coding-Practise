# CounterApp

## Description
A basic counter application demonstrating increment and reset functionality using class components.

## Features
- Increment counter by 1
- Reset counter to 0
- Display current count
- Simple and clean UI

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd CounterApp
npm install
npm run dev
```
