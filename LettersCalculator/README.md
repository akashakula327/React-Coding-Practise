# LettersCalculator

## Description
A simple letter counter that calculates and displays the number of characters typed in real-time as the user enters text.

## Features
- Real-time character counting
- Text input with placeholder
- Visual calculator/stopwatch image
- Clean two-column layout
- Button displays current count

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd LettersCalculator
npm install
npm run dev
```
