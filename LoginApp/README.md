# LoginApp

## Description
A simple login/logout toggle component that switches between "Please Login" and "Welcome User" states with corresponding button text.

## Features
- Toggle between login and logout states
- Dynamic heading and button text
- Clean card-based UI
- Boolean state management

## Tech Stack
- React (Vite)
- Class Components
- CSS

## How to Run
```bash
cd LoginApp
npm install
npm run dev
```
